# Phase 5 — Findings Log

Record all issues discovered during dry-run scenarios. Each finding gets a severity, status, and resolution.

---

## Severity Definitions

| Level | Definition | Action |
|-------|-----------|--------|
| **Critical** | Data loss, security bypass, or workflow blocker | Must fix before pilot continues |
| **High** | Incorrect behavior affecting data integrity or user flow | Must fix before real client data |
| **Medium** | UX issue or minor workflow problem | Fix before staging deployment |
| **Low** | Cosmetic or minor inconvenience | Backlog for future sprint |
| **Feedback** | Workshop-quality UX observation | Add to assessor workshop backlog |
