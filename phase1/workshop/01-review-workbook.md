# Template review workbook — assessor workshop

**Instructions:** For each template below, the facilitator opens the template preview in the prototype (via `/jobs/new` → select the template to see its sections/items). Assessors review the checklist items against their real-world practice and mark corrections on this sheet.

**How to read:** Each template lists its sections and key items. Mark each item:
- **✓** — correct as-is
- **✗ + note** — needs correction (write what should change)
- **+ note** — missing item that should be added
- **−** — item should be removed (explain why)
